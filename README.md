# 素材放置说明

把文件按下面的名字放进本目录（`public/`），页面会自动检测并启用；
不放也能正常运行，对应位置会用生成式视觉兜底。

| 文件名 | 用途 | 建议规格 |
| --- | --- | --- |
| `hero.mp4` | 首屏视频背景 | 1920x1080，5-15s 循环，暗色调，< 8MB |
| `portrait.jpg` | 个人头像/人物图 | 3:4 竖图，900x1200 以上 |
| `work-01.jpg` | 客服工作台架构升级 配图 | 16:10 横图，1600px 宽以上 |
| `work-02.jpg` | 美团平台业务 配图 | 同上 |
| `work-03.jpg` | App 客服大模型 配图 | 同上 |

注意：项目配图如涉及公司内部界面，请先做脱敏处理再放入。
